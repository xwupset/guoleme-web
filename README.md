# 过了么 · 课程作业网页版

课程作业 / 期末项目演示用 Web 应用。把“补考代考服务”做成了一份**纯虚构的点单系统**，体验对标饿了么：

- 首页营销 → 选择学校 → 学校统一身份认证（跳官方页面）→ **一键读取本学期课程 / 学分** → 像点外卖一样选课下单 → 微信 / 支付宝收银台 → 整蛊彩蛋弹窗。
- **不提供真实服务、不会真实扣款、不保存账号密码**。身份 / 课程 / 购物车等数据只保存在本机浏览器 `localStorage`。

## 线上地址（GitHub Pages）

- 正式地址：<https://xwupset.github.io/guoleme-web/>
- 仓库：<https://github.com/xwupset/guoleme-web>

- 注意：**书签小工具要在正式地址上重新生成一次**，因为它会把生成时的网址写进代码。

## 一、怎么运行

### 方式 1：本地静态服务器（推荐）

在项目目录执行：

```bash
python -m http.server 8611
```

然后浏览器打开 <http://127.0.0.1:8611/>。

> 用 `http://127.0.0.1` 打开时浏览器才会开放「一键读取剪贴板」能力；`file://` 直接双击打开会退化成“手动粘贴”。

### 方式 2：直接双击 index.html

双击 `index.html`，用 Chrome / Edge 打开也能使用全部功能（“一键读取”会提示改用粘贴）。

## 二、课表导入的三种方式

### 1. ⚡ 一键读取（推荐，桌面 / 手机通用）

1. 在导课页点击 **直达“选课信息”页**（或先登录教务系统）；
2. 顶部菜单进入 **信息查询 → 查询个人信息 → 选课信息**；
3. 把 **学年选 2026-2027、学期选第 1 学期**，等表格刷出来；
4. 表格区域 `Ctrl+A` → `Ctrl+C`（手机：长按表格 → 全选 → 复制）；
5. 回到本程序，点 **⚡ 一键读取（读取剪贴板）**。

程序会一次性完成：**姓名 + 学号 → 安全验证自动填充；课程名称 + 学分 → 课表自动导入**，并给出导入清单。

### 2. 📎 书签小工具（在教务系统页面里点一下）

导课页最下方的“进阶玩法”里有一个可拖拽的书签按钮：

- 把按钮拖到浏览器书签栏（手机上：复制代码 → 新建书签 → 粘贴到网址栏）；
- 之后在教务系统的**选课信息**页面点一下这个书签，它会自动找到“课程名称 + 学分”表格、读出姓名学号，并**跳回本程序完成导入**。

这是纯网页能实现的最接近“全自动拉取”的方案。生成的代码里写死了本程序的地址，所以要在部署后的正式地址上生成一次。

### 3. 📋 粘贴 / 手动 / 演示课表（兜底）

- 方法 A：把教务系统复制的内容粘进输入框，**粘贴即自动解析**；也可点“预览 / 手动挑选”逐门核对、改名、改学分；
- 方法 B：一键载入 7 门演示课表，或逐门手动添加。

支持的粘贴格式：教务“选课信息”表格原文（Markdown 表格、制表符表格均可）、课表查询页的大段文本、`课程名 学分` 的简单清单。**0.25 这类小学分同样能识别**。

## 三、安全验证（必填）

- 导课页的 **🔐 安全验证** 需要填写**姓名 + 学号**，两项均为必填；
- 一键读取 / 粘贴解析成功后会自动填入，**不需要点任何保存按钮**；
- 鼠标离开输入框（失焦）即自动保存到 `localStorage`；
- 未完成验证时点“进入选课菜单”会被拦截并高亮提示；
- 信息只用于展示订单身份与生成整蛊弹窗，不会上传到任何服务器。

## 七、技术说明与调研结论

### 为什么登录要跳转学校官网，而不是在页面里内嵌并自动抓课表？

浏览器有**同源策略**：A 网站的脚本不能读取 B 网站登录后的页面内容，也无法在 B 网站里注入脚本。所以纯网页无法实现“程序内嵌教务页并自动抓取课程”。

参考的 `D:\QQ下载\base(5).apk` 经分析是 **WakeUp 课程表（Kotlin 版）**：App 内嵌 WebView（相当于完整浏览器），用户登录后打开课表页，再往 WebView 注入 `save2json()` JS 抓取表格。这套方案**只有原生 App / 带 WebView 的壳**才能实现。

网页版因此做了两条贴近它的路径：

1. **剪贴板一键读取**：把“复制课表”这一步自动化掉，用户只按一次按钮；
2. **书签小工具**：在教务系统页面上执行我们自己的 JS（等价于 App 的注入脚本），抓完数据后跳回本程序。

### 如果以后要做“真·自动拉取”

- **包成 Android WebView 壳**：直接复刻 WakeUp 范式，体验最像原生；
- **微信小程序**：`web-view` 与平台安全策略限制较多，需要重新设计；
- **浏览器扩展**：可做到全自动，但分发成本高，不适合课堂。

## 八、隐私与安全

- 无后端、无数据库、无任何网络请求（除页面里主动点击跳转学校官网外）；
- 账号密码只输入在学校官方页面，本程序不接触、不保存；
- 姓名 / 学号 / 课程 / 购物车仅存本机 `localStorage`，页面上有“重置全部本地数据”；
- 顶部横幅与收银台保留“不提供真实服务、不会真实扣款”的说明，其余文案按演示体验收敛。

## 九、文件结构

```
guoleme-web/
├── index.html          页面框架（顶部横幅 / 导航 / 页脚容器）
├── css/style.css       全部样式（饿了么风蓝色主题 + 移动端适配）
├── js/store.js         状态、localStorage、定价规则、学校配置 CONFIG.SCHOOL
├── js/parser.js        课表文本解析 + 书签小工具生成器
└── js/app.js           路由、各页面渲染与交互
```

修改学校信息 / 教务系统地址：编辑 `js/store.js` 的 `CONFIG.SCHOOL`。
