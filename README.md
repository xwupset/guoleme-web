# 过了么 · 课程作业网页版

课程作业 / 期末项目演示用 Web 应用。把“补考代考服务”做成了一份**纯虚构的点单系统**，体验对标饿了么：

- 首页营销 → 选择学校 → **导入本学期课表** → 像点外卖一样选课下单 → 微信 / 支付宝收银台 → 整蛊彩蛋弹窗。
- **不提供真实服务、不会真实扣款、不保存账号密码**。身份 / 课程 / 购物车等数据只保存在本机浏览器 `localStorage`。

---

- 正式地址：<https://xwupset.github.io/guoleme-web/>
- 仓库：<https://github.com/xwupset/guoleme-web>

- 页面带 `noindex`，不会被搜索引擎收录。
- 已做 **PWA**：可“添加到主屏幕”，并且**能从系统分享面板接收课表文件**（见第五节）。

## 一、怎么运行

### 方式 1：本地静态服务器（推荐）

```bash
python -m http.server 8611
```

然后浏览器打开 <http://127.0.0.1:8611/>。

> 用 `http://127.0.0.1` 打开时浏览器才会开放「一键读取剪贴板」和 Service Worker；`file://` 直接双击会退化。

### 方式 2：直接双击 index.html

双击 `index.html` 用 Chrome / Edge 打开也能用（剪贴板读取会提示改用粘贴）。

> ⚠️ **部署约束**：`js/importfile.js` 通过 `document.baseURI + 'lib/'` 定位静态库，
> 所以 **`lib/` 必须和 `index.html` 同级**。搬到别处要同步改这个路径。

## 二、导入课表（核心功能）

入口：顶部导航 **导入课表**（`#/import`）。手机优先设计，三种方式都支持：

### 方式 1：📄 选择文件（推荐）

支持教务系统导出的 **PDF / Excel / CSV**，也支持课表 App 导出的 JSON。

**手机上最快的一条路**：教务系统 → 点「导出 / 下载」→ 文件存到手机 →
在文件管理里 **长按该文件 → 分享 → 选「过了么」** → 直接跳进导入页并自动解析。
（这一步靠的是 PWA 的 `share_target`，见第五节；不需要在文件选择器里再翻一遍。）

### 方式 2：📋 复制粘贴

在教务系统「选课信息」页 `Ctrl+A` → `Ctrl+C`（手机长按表格 → 全选 → 复制），
回到导入页**在页面任意位置粘贴**即可，不用先点中输入框。

### 方式 3：🛠 手动添加 / 演示课表

在导课页的折叠区里，可逐门手动添加或一键载入 7 门演示课表。

### 导入后会自动完成

- ✅ **自动识别姓名与学号**，并填入「安全验证」（不用再打字）；
- ✅ 课程清单逐条列出，可取消勾选、可直接改学分；
- ✅ 缺学分时**拦住不放行**，提示补齐（因为计价完全依赖学分）；
- ✅ 自动跳过课表里已有的同名课程。

## 三、支持的输入格式（均已实测）

| 格式 | 说明 |
| --- | --- |
| `.pdf` | **自研抽取器**，详见第四节 |
| `.xlsx` / `.xls` | SheetJS；含 HTML 伪装的 `.xls` |
| `.csv` | 自动识别 **GBK / GB18030 / UTF-8** 编码，逗号与分号分隔都能处理 |
| `.json` | 课表 App 导出格式（按 `courseName`/`credit` 等常见字段名递归查找） |
| 纯文本 | 直接交给解析器 |

### 解析器能处理的排版

1. **强智「选课信息」表格**：`课程名称 | 学分 | 课程类别 | 考核方式 | …`（学分在前或在后都行）；
2. **周课表网格**：列 = 星期一~日，行 = 第 1~12 节；会自动去重、合并被换行切碎的课名、
   并从「教师:」「共N周」里抽出**任课教师**和**周次**；
3. **底部清单**：`实践课程：毕业实习（S）孙淑晓(共2周)/17-18周; …`；
4. **课表查询页的大段文本**、`课程名 学分` 的简单清单。

> 学分是计价依据。**部分「课表」导出件不含学分列**（只有课程名/教师/周次），
> 这种情况导入页会明确提示并让你补齐。

## 四、技术说明：为什么自己写 PDF 抽取器？

### 问题

教务系统导出的课表 PDF 由 **iText + 宋体 CID 字体**生成
（字体名形如 `STSong-Light-UniGB-UCS2-H`，页面还带 `/Rotate 90`）。
这类 PDF 的文字虽然本身是 UTF-16BE，但字体声明是 CID 字体，
**pdf.js 需要额外下载 CMap 表才能解码**——在离线 / 移动端经常失败，
最终**一行字都读不出来**（实测确认）。

### 方案

`js/pdftext.js` 是一个**完全自给自足**的抽取器：

1. 直接扫 PDF 字节，找出所有流对象；
2. **滤镜链**全支持：`FlateDecode` / `ASCII85Decode` / `ASCIIHexDecode` / `RunLengthDecode` / `LZWDecode`；
   解压用 **fflate**（32KB，同步 API）——刻意不用原生 `DecompressionStream`：
   它是异步流、旧 WebView 不支持、还会让自动化测试无法进行；
3. 递归解析内容流算子：`Tj` / `TJ` / `Td` / `TD` / `Tm` / `T*` / `'` / `"`，并维护 `Tm`/`CTM` 矩阵；
4. 按坐标还原成「行」，带 **CJK 间隙消除**（中文之间不补空格）与
   **表格列间距识别**（避免「姓名：黄宇翔」和「学号：…」粘成一个词）；
5. 文字解码三路择优：**ToUnicode CMap**（子集字体）→ UTF-16BE → Latin-1；
6. 识别「扫描件 / 图片型 PDF」并给出明确提示（`imageOnly`）。

实测 **5~20ms** 解析完一份教务 PDF，**零网络依赖**。

> pdf.js 保留在 `lib/` 里仅作极少数特殊 PDF 的**兜底**：
> 自研抽取器读不出文字时会自动改用它重试一次。
> 如果确定不需要，删掉 `lib/pdf.min.mjs` + `lib/pdf.worker.min.mjs` 可再省 1.7MB。

### 为什么登录必须跳学校官网

浏览器有**同源策略**：A 网站的脚本不能读取 B 网站登录后的内容，也无法注入脚本。

我们做过实测：把闽江学院统一身份认证平台用 `<iframe>` 嵌进来，**视觉上能显示**，
但 `iframe.contentDocument` 返回 `null`，注入脚本直接抛
`SecurityError: Blocked a frame with origin ... from accessing a cross-origin frame`。
设 `document.domain` 抢救也不行（`'mju.edu.cn' is not a suffix of '127.0.0.1'`）。

参考的 `D:\QQ下载\base(5).apk` 经分析是 **WakeUp 课程表（Kotlin 版）**：
它内嵌 `WebView` 并在**原生层**注入 JS 抓表格 —— 这只有 App 能做到，纯网页不行。

所以网页版把力气花在**把「导出 → 导入」这条路打磨到极致**上。

## 五、PWA：为什么做、怎么用

`manifest.json` + `sw.js` 带来两件实际有用的事：

1. **可安装**（添加到主屏幕）——也是进分享面板的前提；
2. **`share_target` / `file_handlers`**：手机上把导出的 PDF **分享给「过了么」**，
   或在文件管理器里选「用过了么打开」，就能直接进入导入流程。

### Service Worker 用 **网络优先（network-first）**

刻意不用「缓存优先」：那会让用户永远落后一个版本 —— 修好的 bug 刷新也拿不到。
这个项目很小，联网时直接取最新最稳，只有断网才回退缓存。

`lib/` 下的大文件（fflate / xlsx / pdf.js）**不接管**，交给浏览器 HTTP 缓存。

## 七、正式使用流程（目标用户操作）

1. 打开首页 → **开始体验**；
2. 搜索学校：输入含“闽江 / 闽 / 江”的关键词命中**闽江学院**；
3. 进入“身份认证与课表导入”页，点 **📥 去导入课表**；
4. 在教务系统里：**信息查询 → 查询个人信息 → 选课信息**，学年选 2026-2027、学期选第 1 学期；
5. 点页面上的**导出 / 下载**（或在表格上 `Ctrl+A` `Ctrl+C`）；
6. 回到导入页 → 选文件（或直接粘贴）→ **核对课程、补齐学分** → 导入；
7. 进入选课菜单 → 勾选课程 → 购物车 → 收银台；
8. 选微信 / 支付宝 → 确认付款 → 整蛊彩蛋弹窗（显示你的姓名与学号）。

## 八、计费规则

- 每门课 **¥49.99** 起；
- 难度关键词匹配的课程“酌情加价”：数学 / 物理类 +20%、背诵量大类 +10%；
- 会员 **¥49/学期**：95 折 + 买三送一（每选满 4 门免 1 门）；
- **准分宝**：目标 ≥80/85/90/95 分，每门分别 +¥39/+69/+109/+169。

> 计价单位是 **「门」**，不是学分 —— 因为教务系统导出的课表 PDF 里
> 常常根本没有学分列，按门计价才能让「下载课表 → 导入 → 下单」这条路走得通。

## 十、文件结构

```
guoleme-web/
├── index.html            页面框架 + PWA meta + 脚本加载顺序
├── manifest.json         PWA 清单（含 share_target / file_handlers）
├── sw.js                 Service Worker（网络优先）
├── img/                  PWA 图标 + favicon
├── css/style.css         全部样式（饿了么风蓝色主题 + 手机优先）
├── lib/
│   ├── fflate.min.js     同步解压（PDF Flate 流）
│   ├── xlsx.full.min.js  SheetJS（Excel / CSV）
│   ├── pdf.min.mjs       pdf.js 兜底
│   └── pdf.worker.min.mjs
└── js/
    ├── store.js          状态、localStorage、计价规则、CONFIG.SCHOOL
    ├── parser.js         课表文本解析（格式 A/B/C）
    ├── pdftext.js        自研 PDF 文本抽取器（滤镜链 + 坐标重排 + ToUnicode）
    ├── timetable.js      周课表网格解析（教师 / 周次 / 去重）
    ├── importfile.js     导入引擎：格式嗅探 + 分派 + 结果汇总
    ├── importui.js       导入页 UI（手机优先）
    └── app.js            路由、各页面渲染与交互、PWA 启动
```

**脚本加载顺序有依赖**，不要随意调整：
`store → parser → pdftext → timetable → importfile → importui → app`。

修改学校信息 / 教务系统地址：编辑 `js/store.js` 的 `CONFIG.SCHOOL`。
修改价格：编辑 `js/store.js` 的 `CONFIG.COURSE_FEE` / `MEMBER_FEE` / `SCORE_BAO`。

## 十一、已知限制 / TODO

- 部署时 **`lib/` 必须与 `index.html` 同级**（路径由 `document.baseURI` 推导）；
- **图片型 / 扫描件 PDF 无法解析**（不做 OCR）。导入页会明确提示，并建议改用导出 Excel
  或先用手机相册的「长按取字」复制文字；
- 老 WebView / 隐私模式下 Service Worker 可能注册失败，此时只是失去「分享导入」，
  不影响手动选文件与粘贴；
- 「切回来高亮」依赖 `visibilitychange` 事件：桌面浏览器切标签页、手机切 App 都能触发，
  但如果浏览器把页面完全挂起（极端省电模式），可能不会触发；
- 粘贴解析仍为启发式规则，不同教务页面排版不同，导入前请核对（结果可编辑）。

---

## 十二、隐私与安全

- 无后端、无数据库、无任何网络请求（除页面里主动点击跳转学校官网外）；
- **所有文件解析都在本机浏览器内完成**，文件不会上传到任何服务器；
- 账号密码只输入在学校官方页面，本程序不接触、不保存；
- 姓名 / 学号 / 课程 / 购物车仅存本机 `localStorage`，页面上有“重置全部本地数据”；
- 测试用的静态库均为本地内置，不依赖任何 CDN。
